# Fictional fraud-policy knowledge base

This directory contains original, fictional guidance written for the Financial
Fraud Intelligence Platform portfolio project. It does not reproduce or adapt
an employer, client, regulator, or real financial institution's policies.

The documents are the source material for the RAG analyst assistant planned in
PH9-02. They are deliberately stored as readable Markdown so a reviewer can
inspect the guidance without running an AI system.

## Contents

- `policies/fraud-investigation-policy.md` defines the investigation process.
- `policies/fraud-escalation-policy.md` defines fictional escalation decisions.
- `guides/analyst-investigation-guide.md` applies the policies to supported
  fictional scenarios.
- `guides/risk-and-alert-interpretation.md` explains model and alert outputs.
- `manifest.json` provides stable document and section metadata for future
  source-aware retrieval.

Source and section identifiers are intentionally stable. PH9-02 may use them in
citations even if the documents later move between development machines.

## Safety boundary

All people, roles, processes, examples, and the organization name Harborline
Pay are fictional. The corpus contains no customer records, credentials,
personal data, legal advice, or real organization-specific rules. Its guidance
is educational and must not be treated as production fraud policy.
